🚀 DEPLOYMENT STEPS:

  1. Commit to GitHub
     $ git add .
     $ git commit -m "Make Vercel-ready: dynamic backend URL + env vars"
     $ git push origin main

  2. Deploy Frontend
     • Go to https://vercel.com/new
     • Select your GitHub repository
     • Vercel auto-detects Vite setup
     • Add environment variable: VITE_BACKEND_URL=http://localhost:3000 (temp)
     • Deploy ✅

  3. Deploy Backend
     • Create another Vercel project
     • Select same GitHub repository
     • Root Directory: ./ (project root)
     • Build: (leave empty - no build)
     • Start Command: node server.js
     • Deploy ✅

  4. Set Environment Variables in Vercel
     
     Frontend (.env):
       - VITE_BACKEND_URL = https://your-backend-vercel.app
     
     Backend (.env):
       - MONGODB_URI = your-production-mongodb-uri
       - JWT_SECRET = new-production-secret
       - GOOGLE_CLIENT_ID = your-google-id
       - GOOGLE_CLIENT_SECRET = your-google-secret
       - RESEND_API_KEY = your-resend-key
       - CLIENT_URL = https://your-frontend-vercel.app

  5. Update Google OAuth Console
     • Authorized JavaScript origins:
       - https://your-frontend-vercel.app
       - https://your-backend-vercel.app
     
     • Authorized redirect URIs:
       - https://your-backend-vercel.app/api/auth/google/callback

  6. Test Live
     • Open frontend URL
     • Test sign up, login, Google OAuth, forgot password


🔒 SECURITY REMINDERS:

  ⚠️  NEVER commit .env to Git (already in .gitignore ✓)
  ⚠️  ALWAYS use Vercel dashboard for secrets
  ⚠️  Use DIFFERENT secrets for production (not dev secrets)
  ⚠️  Keep GOOGLE_CLIENT_SECRET private
  ⚠️  Don't share Vercel environment variable values


📝 LOCAL DEVELOPMENT:
